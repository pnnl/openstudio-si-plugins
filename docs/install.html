OpenStudio SI installation

Choose the installation path that fits how you work.

Use the terminal for scripted or repository-local setup, or install directly from the standalone desktop clients. Both paths add the same OpenStudio SI plugin.

Terminal-based installation ↓Desktop-client installation ↓
Terminal Desktop client OpenStudio-MCP
Option 1

Terminal-based installation

Use the marketplace commands when you want repeatable setup from a shell.

Claude Code

Add the marketplace, install the plugin, then reload it in the session.

1

Add the marketplace

claude plugin marketplace add https://github.com/pnnl/openstudio-si-plugins.git
2

Install the plugin

claude plugin install openstudio-si@openstudio-si-local
3

Reload and run setup

/reload-plugins
/openstudio-si:setup-openstudio-si
4

Update the plugin

Refresh the marketplace to retrieve the latest OpenStudio SI release, then reload plugins in an active session.

claude plugin marketplace update openstudio-si-local
/reload-plugins

Codex

Add the marketplace, install the plugin, then run setup in a task.

1

Add the marketplace

codex plugin marketplace add https://github.com/pnnl/openstudio-si-plugins.git
2

Install the plugin

codex plugin add openstudio-si@openstudio-si-local
3

Run setup in a task

$setup-openstudio-si
4

Update the plugin

Refresh the marketplace to retrieve the latest OpenStudio SI release, then start a new task or reopen Codex.

codex plugin marketplace upgrade openstudio-si-local

For project-wide Codex policy setup and local-folder installation, see the repository’s Codex instructions. For Claude Code scopes and validation, see the Claude Code instructions.

Option 2

Desktop-client installation

Add the marketplace through the application UI, then install OpenStudio SI. The equivalent steps are arranged side by side so you can follow the client you use.

Claude Code Desktop

Open the Plugins directory to add and install OpenStudio SI.

1

Add the marketplace

Open Customize → Plugins → Browse, then click the + button. Paste the repository URL in the Add marketplace window and select the suggested Use option.

https://github.com/pnnl/openstudio-si-plugins.git
2

Install OpenStudio SI

Select openstudio-si-local, then click + beside OpenStudio SI.

3

Run setup

Start a session for your project, type /openstudio-si:setup-openstudio-si, and select the setup skill.

Codex Desktop

Open Customize, then Plugins, to add and install OpenStudio SI.

1

Add the marketplace

Open Plugins, click the Add dropdown, then select + Add marketplace. Paste the source and select Add marketplace.

https://github.com/pnnl/openstudio-si-plugins.git
2

Install OpenStudio SI

Under Personal → OpenStudio SI Local, click + beside OpenStudio SI.

3

Run setup in a task

Open a project task, type $setup-openstudio-si, and choose OpenStudio SI: Setup OpenStudio SI.

Keep OpenStudio SI current

Update a desktop plugin

When a newer OpenStudio SI version is available, follow the update steps for the desktop client you use.

Claude Code Desktop

First refresh the marketplace, then update the installed OpenStudio SI plugin.

1

Check the marketplace for updates

Open Manage plugins → Browse → Personal. Open the openstudio-si-local menu and select Check for updates.

2

Update the installed plugin

Return to the OpenStudio SI plugin page and click Update.

Codex Desktop

Updating the marketplace also updates the locally installed OpenStudio SI plugin.

1

Upgrade the marketplace

Open Plugins, select the Marketplace tab, then click Upgrade for OpenStudio SI Local. No separate local-plugin update is needed.

The setup skill checks your local runtime and explains any missing requirements before you begin modeling.

Optional terminal step

Add OpenStudio-MCP

OpenStudio SI works with the plugin alone. Add OpenStudio-MCP when your workflow needs its local, containerized OpenStudio capabilities.

Docker-based provider

Prepare the local OpenStudio-MCP runtime

Install and start Docker Desktop first, then download the OpenStudio-MCP image. The provider setup guide covers the final client configuration and required Docker mounts.

macOS with Homebrew

Install Docker Desktop and confirm that it is running.

brew install --cask docker
open -a Docker
docker version

Windows PowerShell

Install Docker Desktop and confirm that Docker is available.

winget install -e --id Docker.DockerDesktop
docker version

Pull and connect

Download the image, then configure it for your chosen client.

docker pull nrel/openstudio-mcp:devOpenStudio-MCP setup guide ↗
