# OpenStudio SI 0.4.2 is available

OpenStudio SI is the new name for the building energy modeling software introduced as OpenStudio AI. It connects Codex and Claude Code to OpenStudio so you can inspect and edit models, run simulations, and query results from your project.

Install OpenStudio SI as a fresh setup. If you already use an OpenStudio AI plugin or MCP connection, disable it in your host before enabling OpenStudio SI. Start in a fresh project or review the existing OpenStudio AI instructions in your project before running setup. Existing OpenStudio AI workspaces and saved sessions do not migrate automatically. Keep those files if you need to revisit previous work.

Follow the [Codex installation guide](../INSTALL.codex.md) or the [Claude Code installation guide](../INSTALL.claude.md). The Python runtime is available on [PyPI as `openstudio-si`](https://pypi.org/project/openstudio-si/0.4.2/).
